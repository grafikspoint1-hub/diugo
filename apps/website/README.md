# Website Workspace

Target: Next.js, React and TypeScript.

The customer homepage and initial customer routes are implemented in `app/`. The existing customer and seller HTML prototypes are preserved in `prototypes/` as visual and workflow references. See the root `DEVELOPMENT_STATUS.md` for current readiness.

Run the customer website from the repository root with `npm run dev:website`, then open `http://localhost:3000`. Use `npm run typecheck:website` and `npm run build:website` to verify it.
